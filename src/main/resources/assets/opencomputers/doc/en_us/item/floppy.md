# Floppy Disk

![Many inches.](oredict:oc:floppy)

The floppy disk is the cheapest and smallest type of storage medium in OpenComputers. It holds 512 KB and is a raw disk in Linux. Format it with `mke2fs`, then `mount` it. It is a handy early-game way of storing data and transferring it between [computers](../general/computer.md) and [robots](../block/robot.md). Floppies can be inserted and removed while the machine is running.
