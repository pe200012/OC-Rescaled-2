# Graphics Card

![Fancy images.](oredict:oc:graphicsCard1)

The graphics card is a component that programs can call to display text on a connected [screen](../block/screen1.md). It is not needed for the Linux console, which draws onto the screen directly.

There is only one kind of graphics card. Like all [screens](../block/screen1.md), it supports resolutions up to 160x50 and 256 colors.
