# Data Card

![Contrary to popular belief, it does not store data.](oredict:oc:dataCard1)

The data card is a utility card that provides a couple of algorithms which would be relatively slow to run in a program. It provides hashing functionalities, as well as basic inflate/deflate. Programs reach it as a device on the device bus.

Keep in mind that there is a limit to the size of data that can be processed at a time, and that each operation consumes a bit of energy.
