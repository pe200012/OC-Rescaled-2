# Memory

![Do you remember, dancing in September~](oredict:oc:ram1)

Memory is, like the [CPU](cpu1.md), an essential part in all [computers](../general/computer.md). The memory decides how large the programs can be that a [computer](../general/computer.md) runs. Linux needs at least 8 MB to start, and 16 MB is comfortable. Bare-metal programs run with any amount.

RAM comes in the following sizes:
- 1 MB
- 2 MB
- 4 MB
- 8 MB
- 16 MB
- 32 MB

The sticks are named after their size, for example "Memory (16MB)". Two sticks of one size can be crafted into one stick of the next size. All installed sticks add up. Each MB of memory also adds to the energy a machine uses.

Changing the memory needs a reboot of the machine.
