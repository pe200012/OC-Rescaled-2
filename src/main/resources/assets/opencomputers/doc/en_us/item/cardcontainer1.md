# Card Container

![Can haz cards!](oredict:oc:cardContainer1)

The card container is a container upgrade for [robots](../block/robot.md) allowing cards to be inserted/removed to/from [robots](../block/robot.md) on-the-fly. The slot takes cards of any tier. Unlike normal upgrades, the complexity of containers is twice that of normal upgrades. See [here](../block/robot.md) for details on robot complexity.
