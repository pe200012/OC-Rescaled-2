# CPU

![Braaainz.](oredict:oc:cpu1)

The central processing unit is a core part for each [computer](../general/computer.md) or [server](server1.md). It is a 64-bit RISC-V processor that runs Linux or bare-metal programs.

There is only one kind of CPU. Its clock rate can be 25, 50, 100 or 200 MHz. Use the CPU item while sneaking to switch between them. New CPUs run at 50 MHz. Faster clocks run programs faster, but draw more power.

The CPU supports up to 16 components. In [servers](server1.md), [component buses](componentBus1.md) raise this further. If more components are connected to a [computer](../general/computer.md), it will no longer be able to start, and if it was running, it will crash.
