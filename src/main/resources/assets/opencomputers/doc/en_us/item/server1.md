# Server

![Serves u right.](oredict:oc:server1)

Servers are a form of higher grade [computer](../general/computer.md). They run Linux like any other computer. They can be configured by holding them in the hand and using them - like opening a backpack or Ender pouch, for example. Servers can also be configured after having been installed into a [rack](../block/rack.md) by activating them (aiming at the corresponding position on the front face on the [rack](../block/rack.md)). To operate, the server has to be placed inside a [rack](../block/rack.md). For more information see the [rack](../block/rack.md) entry.

There is only one kind of server (plus a creative one). It is capable of taking the following components:
- 1x [CPU](cpu1.md)
- [RAM](ram1.md)
- [HDD](hdd1.md)
- [Component bus](componentBus1.md)
- Expansion cards
- 1x [EEPROM](eeprom.md)

Every slot takes items of any tier.
