# Computer Case

![Just in case.](oredict:oc:case1)

The computer case holds the parts of a [computer](../general/computer.md): [CPU](../item/cpu1.md), [RAM](../item/ram1.md), [hard drives](../item/hdd1.md), expansion cards and an [EEPROM](../item/eeprom.md). There is one kind of computer case; an additional creative-only case also exists. Any slot takes items of any tier.

A computer runs Linux. It boots what is on its EEPROM, and the first hard drive gets Linux installed automatically the first time the computer starts. Without a hard drive Linux runs as a live system from memory, and nothing is kept when it stops. Computer cases can also be placed inside an [assembler](assembler.md) to build [robots](robot.md).

A [screen](screen1.md) touching the case is used for the console, and a [keyboard](keyboard.md) attached to that screen is used to type.
