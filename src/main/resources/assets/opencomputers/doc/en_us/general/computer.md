# Computers

Computers are built using a variety of different [blocks](../block/index.md) and components. The bare minimum needed to build a usable computer is a [case](../block/case1.md), a [screen](../block/screen1.md) and a [keyboard](../block/keyboard.md). The [keyboard](../block/keyboard.md) must be placed on the [screen](../block/screen1.md), either on its sides or directly in front of it. The computer uses the [screen](../block/screen1.md) touching its [case](../block/case1.md) if there is one, otherwise the first one it finds on its network, and only reads [keyboards](../block/keyboard.md) attached to that [screen](../block/screen1.md). Several computers connected with [cables](../block/cable.md) therefore do not draw on each other's [screens](../block/screen1.md).

Inside the [case](../block/case1.md) go the components: a [CPU](../item/cpu1.md), [memory (RAM)](../item/ram1.md), an [EEPROM](../item/eeprom.md) with the Linux boot loader and, usually, a [hard drive (HDD)](../item/hdd1.md). Further components add abilities: [network cards](../item/lanCard.md) and [internet cards](../item/internetCard.md) become network interfaces in Linux, a [redstone card](../item/redstoneCard1.md) lets programs read and set redstone, and so on. No [graphics card](../item/graphicsCard1.md) is needed for the console. See [getting started](quickstart.md) for a step-by-step setup.

The computer runs [Linux](linux.md) on an emulated 64-bit RISC-V processor. The first time it starts with a [hard drive](../item/hdd1.md), Linux is installed onto that drive. Without a [hard drive](../item/hdd1.md) it runs a live system from memory, which forgets everything when the computer stops. Additional [hard drives](../item/hdd1.md) and [floppy disks](../item/floppy.md) are plain disks in Linux, see [Linux](linux.md).

A running computer is saved together with the world, memory and all, and continues where it left off when its chunk is loaded again. Shut it down from Linux with `poweroff`, or restart it with `reboot`. Changes to the [memory](../item/ram1.md), [hard drives](../item/hdd1.md), network cards or [EEPROM](../item/eeprom.md) take effect when the computer restarts; other components can be added and removed while it runs.

The final step necessary is to provide the computer with a power source. OpenComputers is compatible with most major power-providing mods, and many blocks can be powered directly. You can see which blocks can be connected to external power by checking if their tooltip contains an entry about the block's power conversion speed. How much a computer draws depends on its [CPU](../item/cpu1.md)'s clock rate and its amount of [memory](../item/ram1.md).
For a larger network with multiple computers, a [power converter](../block/powerConverter.md) (converts different mod's power to OC's internal Energy type), [power distributor](../block/powerDistributor.md) (distributes power to different computers on the network), and [capacitor](../block/capacitor.md) (power storage for the network) can be used to connect different computers on the network using [cables](../block/cable.md).
