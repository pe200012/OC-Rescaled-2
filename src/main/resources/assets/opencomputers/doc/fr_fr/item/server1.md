# Serveur

![Ca te servira de leçon.](oredict:oc:server1)

Les serveurs sont une sorte d'[ordinateur](../general/computer.md) de haut niveau. Ils exécutent Linux comme n'importe quel autre ordinateur. Ils peuvent être configurés en les tenant en main et en les utilisant en même temps - comme pour ouvrir un sac à dos ou une Bourse du Néant (d'EnderStorage), par exemple. Les serveurs peuvent aussi être configurés après avoir été installés dans un [support de serveur](../block/rack.md) en les activant (en visant la position correspondante sur la face avant du [support de serveur](../block/rack.md)). Pour fonctionner, le serveur doit être placé dans un [support de serveur](../block/rack.md). Pour plus d'informations, allez voir l'entrée sur le [support de serveur](../block/rack.md).

Il n'existe qu'un seul type de serveur (plus un type créatif). Il est capable d'accueillir les composants suivants :
- 1x [processeur](cpu1.md)
- [RAM](ram1.md)
- [disque dur](hdd1.md)
- [Bus de composant](componentBus1.md)
- Cartes d'extension
- 1x [EEPROM](eeprom.md)

Chaque emplacement accepte des objets de n'importe quel niveau.
