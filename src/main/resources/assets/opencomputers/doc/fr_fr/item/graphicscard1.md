# Carte graphique

![Images fantaisie.](oredict:oc:graphicsCard1)

La carte graphique est un composant que les programmes peuvent appeler pour afficher du texte sur un [écran](../block/screen1.md) connecté. Elle n'est pas nécessaire pour la console Linux, qui s'affiche directement sur l'écran.

Il n'existe qu'un seul type de carte graphique. Comme tous les [écrans](../block/screen1.md), elle supporte des résolutions jusqu'à 160x50 et 256 couleurs.
