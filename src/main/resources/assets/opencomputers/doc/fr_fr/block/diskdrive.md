# Lecteur de disquettes

![Silence, on tourne !](oredict:oc:diskDrive)

Le lecteur de disquettes peut être utilisé pour lire des [disquettes](../item/floppy.md) en se servant d'un [ordinateur](../general/computer.md) connecté au lecteur. Sous [Linux](../general/linux.md), une disquette est un disque brut de 512 Ko. Chaque lecteur de disquettes que la machine peut voir (jusqu'à 4) est un lecteur, numéroté après les disques durs. Formatez une disquette avec `mke2fs`, puis montez-la avec `mount`. Les disquettes peuvent être insérées et retirées pendant que la machine fonctionne, mais un lecteur de disquettes nouvellement connecté nécessite un redémarrage.

Il peut également être installé sur les [robots](robot.md) pour pouvoir insérer des [disquettes](../item/floppy.md) dans le [robot](robot.md). Cela peut être très utile car le seul autre moyen de transférer des données vers et depuis un robot est d'utiliser le réseau - par exemple en utilisant une [carte réseau](../item/lanCard.md).

Les [disquettes](../item/floppy.md) peuvent être insérées et retirées sans ouvrir l'interface du lecteur de disquettes en faisant un clic-droit en étant accroupi (shift + clic droit) avec la [disquette](../item/floppy.md) en main.
