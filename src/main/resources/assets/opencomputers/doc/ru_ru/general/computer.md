# Компьютеры

Компьютеры собираются из различных [блоков](../block/index.md) и компонентов. Минимальный набор для создания рабочего компьютера: [системный блок](../block/case1.md), [монитор](../block/screen1.md) и [клавиатура](../block/keyboard.md). [Клавиатура](../block/keyboard.md) должна быть расположена на [мониторе](../block/screen1.md): на одной из его сторон или непосредственно перед ним. Компьютер использует [монитор](../block/screen1.md), прилегающий к его [системному блоку](../block/case1.md), если он есть, а иначе первый найденный в его сети, и читает только [клавиатуры](../block/keyboard.md), подключённые к этому [монитору](../block/screen1.md). Поэтому несколько компьютеров, соединённых [кабелями](../block/cable.md), не выводят изображение на [мониторы](../block/screen1.md) друг друга.

Внутрь [системного блока](../block/case1.md) помещаются компоненты: [процессор](../item/cpu1.md), [планки памяти (RAM)](../item/ram1.md), [EEPROM](../item/eeprom.md) с загрузчиком Linux и, как правило, [жесткий диск (HDD)](../item/hdd1.md). Остальные компоненты добавляют возможности: [сетевые карты](../item/lanCard.md) и [интернет карты](../item/internetCard.md) становятся сетевыми интерфейсами в Linux, [плата на красном камне](../item/redstoneCard1.md) позволяет программам читать и подавать сигнал красного камня, и так далее. Для консоли [видеокарта](../item/graphicsCard1.md) не нужна. Пошаговую инструкцию по сборке смотрите в разделе [быстрый старт](quickstart.md).

Компьютер работает под управлением [Linux](linux.md) на эмулируемом 64-битном процессоре RISC-V. При первом запуске с [жестким диском](../item/hdd1.md) Linux устанавливается на этот диск. Без [жесткого диска](../item/hdd1.md) компьютер работает как живая система из памяти, которая забывает всё при остановке компьютера. Дополнительные [жесткие диски](../item/hdd1.md) и [дискеты](../item/floppy.md) в Linux являются обычными дисками, см. [Linux](linux.md).

Работающий компьютер сохраняется вместе с миром, вместе с памятью, и продолжает работу с того же места, когда его чанк снова загружается. Выключите его из Linux командой `poweroff` или перезапустите командой `reboot`. Изменения [памяти](../item/ram1.md), [жестких дисков](../item/hdd1.md), сетевых карт или [EEPROM](../item/eeprom.md) вступают в силу при перезапуске компьютера; остальные компоненты можно добавлять и убирать во время работы.

Наконец, нужно подключить компьютер к энергии. OpenComputers совместим с самыми популярными модами с энергией, что позволяет подключать многие блоки напрямую. Вы можете узнать, что блок может быть подключен ко внешнему источнику энергии, если в его всплывающей подсказке есть информация о скорости преобразования энергии. Сколько потребляет компьютер, зависит от тактовой частоты его [процессора](../item/cpu1.md) и объёма [памяти](../item/ram1.md).
В больших сетях со множеством компьютеров можно использовать [конвертер энергии](../block/powerConverter.md) (конвертирует энергию других модов во внутренний тип энергии OC), [распределитель энергии](../block/powerDistributor.md) (распределяет энергию между компьютерами в сети) и [конденсатор энергии](../block/capacitor.md) (энергохранилище для сети) для подключения компьютеров с помощью [кабелей](../block/cable.md).
