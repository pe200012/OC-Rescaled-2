# Системный блок

![Просто коробка.](oredict:oc:case1)

Системный блок содержит детали [компьютера](../general/computer.md): [процессор](../item/cpu1.md), [планки памяти](../item/ram1.md), [жесткие диски](../item/hdd1.md), платы расширения и [EEPROM](../item/eeprom.md). Существует один вид системного блока; также есть дополнительный системный блок только для творческого режима. Любой слот принимает предметы любого уровня.

Компьютер работает под управлением Linux. Он загружает то, что записано в его EEPROM, а на первый жесткий диск Linux устанавливается автоматически при первом запуске компьютера. Без жесткого диска Linux работает как живая система из памяти, и после остановки ничего не сохраняется. Системные блоки также можно поместить в [сборщик](assembler.md) для создания [роботов](robot.md).

[Монитор](screen1.md), прилегающий к системному блоку, используется для консоли, а [клавиатура](keyboard.md), установленная на этот монитор, - для ввода текста.
