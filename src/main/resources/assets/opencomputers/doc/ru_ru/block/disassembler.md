# Разборщик

![Построй это, снеси это.](oredict:oc:disassembler)

Разборщик используется, чтобы разбирать большинство предметов OpenComputers на исходные детали. Это удобно для возврата материалов из старых и ненужных деталей, а также для разборки устройств, которые вам больше не нужны или были собраны неправильно (например, [роботы](robot.md) без [операционной системы](../general/linux.md)).

Разборка требует много времени и немного энергии. Также есть небольшой шанс потерять компонент (он применяется для каждого компонента по отдельности).
