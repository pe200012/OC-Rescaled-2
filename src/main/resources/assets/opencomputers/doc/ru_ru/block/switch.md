# Коммутатор

![Строит мосты.](oredict:oc:switch)

*Этот блок устарел и будет удален в следующих версиях.* Превратите его в [ретранслятор](relay.md) в верстаке, чтобы не потерять его.

Коммутатор может быть использован для того, чтобы разные подсети могли отправлять друг другу сообщения, не предоставляя компоненты [компьютерам](../general/computer.md) в других сетях. Обычно полезно оставлять компоненты локальными, чтобы [компьютеры](../general/computer.md) не использовали чужой [монитор](screen1.md).

Существует также беспроводная версия этого блока, называемая [точкой доступа](accessPoint.md), которая также пересылает сообщения по беспроводной сети. Беспроводные сообщения могут быть получены и переданы дальше другими [точками доступа](accessPoint.md) или [компьютерами](../general/computer.md) с [беспроводной сетевой картой](../item/wlanCard1.md).

Коммутаторы и [точки доступа](accessPoint.md) *не* отслеживают, какие пакеты они недавно передали, поэтому избегайте петель в сети, иначе вы можете получать один и тот же пакет несколько раз. Из-за ограниченного буфера коммутатора слишком частая отправка сообщений приведёт к потере пакетов. Скорость, с которой они передают сообщения, ограничена; увеличьте ограничения в конфигурации для большей скорости.

Сообщения могут быть перенаправлены всего несколько раз, поэтому невозможно сделать цепочки с произвольным количеством коммутаторов или точек доступа. По умолчанию сообщение может быть перенаправлено до пяти раз.
