# Красный контроллер

![Привет Ред.](oredict:oc:redstone)

Красный контроллер может быть использован для удалённого чтения и подачи сигналов красного камня. Он ведёт себя как [плата на красном камне](../item/redstoneCard1.md): может читать и подавать простые аналоговые, а также комбинированные сигналы, но не может читать и подавать беспроводные сигналы красного камня.

При указании стороны в методах компонента, предоставляемого этим блоком, направления являются глобальными сторонами света мира. На текстуре блока есть небольшие углубления, соответствующие числовому значению каждой стороны. В micropython после `from devices import bus` используйте `rs = bus.find("redstone")`, а затем, например, `rs.setOutput(1, 15)`.

Как и [платы на красном камне](../item/redstoneCard1.md), этот блок отправляет подключённым [компьютерам](../general/computer.md) сигнал-событие (читается с помощью `bus.wait_event()`) при изменении состояния сигнала красного камня - как для аналоговых, так и для комбинированных сигналов. Также этот блок можно настроить так, чтобы он включал подключённые [компьютеры](../general/computer.md), когда превышена определённая сила входящего сигнала, что позволяет автоматически запускать [компьютеры](../general/computer.md).
