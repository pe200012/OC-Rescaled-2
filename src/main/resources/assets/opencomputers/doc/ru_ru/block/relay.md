# Ретранслятор

![Строит мосты.](oredict:oc:relay)

Ретранслятор может быть использован для того, чтобы разные подсети могли отправлять друг другу сообщения, не предоставляя компоненты [компьютерам](../general/computer.md) в других сетях. Обычно полезно оставлять компоненты локальными, чтобы [компьютеры](../general/computer.md) не использовали чужой [монитор](screen1.md).

Ретранслятор можно улучшить, вставив [беспроводную сетевую карту](../item/wlanCard1.md), чтобы он также пересылал сообщения по беспроводной сети. Беспроводные сообщения могут быть получены и переданы дальше другими ретрансляторами с беспроводной сетевой картой или [компьютерами](../general/computer.md) с беспроводной сетевой картой. Сетевые карты отображаются в Linux как интерфейсы Ethernet, а кадры проходят через ретранслятор как обычные сетевые сообщения, поэтому TCP/IP работает между машинами.

Также ретранслятор можно улучшить с помощью [соединённых карт](../item/linkedCard.md). В этом случае он будет пересылать сообщения и через туннель, предоставляемый соединённой картой, по обычной стоимости, поэтому убедитесь, что ретранслятор достаточно обеспечен энергией.

Ретрансляторы *не* отслеживают, какие пакеты они недавно передали, поэтому избегайте петель в сети, иначе вы можете получать один и тот же пакет несколько раз. Из-за ограниченного буфера ретранслятора слишком частая отправка сообщений приведёт к потере пакетов. Скорость, с которой они передают сообщения, ограничена; увеличьте ограничения в конфигурации для большей скорости.

Сообщения могут быть перенаправлены всего несколько раз, поэтому невозможно сделать цепочки с произвольным количеством ретрансляторов. По умолчанию сообщение может быть перенаправлено до пяти раз.
