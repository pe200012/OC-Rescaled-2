# 3D принтер

![2D печать - прошлый век.](oredict:oc:printer)

3D принтеры позволяют печатать блоки любой формы и с любой текстурой. Чтобы начать работу с 3D принтерами, вам нужно установить блок 3D принтера рядом с компьютером. Это даст доступ к API компонента `printer3d`, позволяя настраивать и печатать [модели](print.md) с помощью предоставляемых функций.

В Linux принтер является устройством на шине устройств, поэтому с ним может работать программа на micropython:
`from devices import bus`
`p = bus.find("printer3d")`
`print(p)` выводит список его методов.

Чтобы принтер мог печатать модели, его нужно настроить с помощью [компьютера](../general/computer.md). Если установлена непрерывная печать, компьютер после этого больше не потребуется. Вам также потребуется предоставить [картридж с чернилами](../item/inkCartridge.md) и немного [хамелиума](../item/chamelium.md) в качестве материалов. Количество используемого хамелиума зависит от объёма 3D печати, а количество чернил - от площади поверхности печатаемого предмета.

Задайте формы, текстуры и название с помощью методов компонента, а затем запустите печать командой `p.commit(1)`.
