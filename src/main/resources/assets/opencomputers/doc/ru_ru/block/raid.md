# RAID

![40 человек в 1.](oredict:oc:raid)

RAID содержит три [жестких диска](../item/hdd1.md), которые объединяются в одну файловую систему. Размер этой объединённой файловой системы равен сумме объёмов отдельных [жестких дисков](../item/hdd1.md), и она доступна всем [компьютерам](../general/computer.md), подключённым к RAID. RAID не является диском Linux. Машины с Linux получают к нему доступ только через шину устройств, как к устройству `filesystem` (открытие, чтение, запись, список файлов и т. д., как в файловом API OpenComputers).

RAID работает (и отображается как файловая система) только при наличии трёх [жестких дисков](../item/hdd1.md). [Жесткие диски](../item/hdd1.md) могут отличаться по размеру.

Помните, что при добавлении [жесткого диска](../item/hdd1.md) в RAID его содержимое будет стёрто. Если убрать один [жесткий диск](../item/hdd1.md) из полного RAID, будет стёрт весь RAID. Возвращение диска *не* восстановит старые файлы: RAID будет заново инициализирован как пустая файловая система.

При разрушении RAID его содержимое сохраняется, поэтому его можно безопасно переносить, не теряя данные.
