# Видеокарта

![Красивые картинки.](oredict:oc:graphicsCard1)

Видеокарта - это компонент, который могут вызывать программы, чтобы отображать текст на подключённом [мониторе](../block/screen1.md). Для консоли Linux она не нужна: консоль рисуется прямо на мониторе.

Существует только один вид видеокарты. Как и все [мониторы](../block/screen1.md), она поддерживает разрешение до 160x50 и 256 цветов.
