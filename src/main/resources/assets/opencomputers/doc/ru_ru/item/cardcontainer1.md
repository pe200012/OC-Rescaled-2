# Контейнер для карт

![Может хранить карты!](oredict:oc:cardContainer1)

Контейнер для карт - это улучшение-контейнер для [роботов](../block/robot.md), позволяющее вставлять и вынимать карты в [роботов](../block/robot.md) и из них на лету. Слот принимает карты любого уровня. В отличие от обычных улучшений, сложность контейнеров вдвое выше сложности обычных улучшений. Подробности о сложности роботов смотрите [здесь](../block/robot.md).
