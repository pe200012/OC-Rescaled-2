# Сервер

![Так тебе и надо.](oredict:oc:server1)

Серверы - это более продвинутая форма [компьютера](../general/computer.md). Они работают под управлением Linux, как и любой другой компьютер. Их можно настраивать, держа в руке и используя - как, например, открывая рюкзак или сумку Эндера. Серверы также можно настраивать после установки в [серверную стойку](../block/rack.md), активируя их (наведясь на соответствующую позицию на передней грани [стойки](../block/rack.md)). Для работы сервер должен быть помещён в [серверную стойку](../block/rack.md). Для получения дополнительной информации смотрите описание [серверной стойки](../block/rack.md).

Существует только один вид сервера (плюс творческий). Он позволяет использовать следующие компоненты:
- 1 [процессор](cpu1.md)
- [планки памяти](ram1.md)
- [жесткие диски](hdd1.md)
- [Компонентные шины](componentBus1.md)
- Платы расширения
- 1 [EEPROM](eeprom.md)

Каждый слот принимает предметы любого уровня.
