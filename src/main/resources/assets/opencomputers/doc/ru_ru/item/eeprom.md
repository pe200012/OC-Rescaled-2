# EEPROM

![Начнем вечеринку.](oredict:oc:eeprom)

EEPROM вмещает 64 КБ и содержит код, который позволяет загрузить компьютер при его запуске. Компьютер загружает то, что записано в его EEPROM, и это должна быть программа RISC-V. Если скрафтить EEPROM вместе с [руководством](manual.md), получится "EEPROM (Linux)", содержащий загрузчик Linux.

EEPROM могут быть запрограммированы автономными программами для специальных целей, таких как [дроны](drone.md) и [микроконтроллеры](../block/microcontroller.md). Если в EEPROM записан текст, компьютер сообщает "EEPROM holds text, not a RISC-V program". Если EEPROM отсутствует или пуст, компьютер сообщает "no bootable EEPROM". Используйте [анализатор](analyzer.md) на машине, чтобы увидеть ошибки загрузки.
