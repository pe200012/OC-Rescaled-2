# Компонентная шина

![Мне нужно боооооольше.](oredict:oc:componentBus1)

Компонентная шина - это улучшение, специфичное для [сервера](server1.md), которое позволяет [серверу](server1.md) взаимодействовать с большим количеством компонентов одновременно без выключения. Каждая компонентная шина добавляет 16 компонентов к тому, что поддерживает [процессор](cpu1.md).
