# Оперативная память

![Do you remember, dancing in September~](oredict:oc:ram1)

Память, как и [процессор](cpu1.md), - неотъемлемая часть всех [компьютеров](../general/computer.md). Именно память определяет, насколько большими могут быть программы, которые запускает [компьютер](../general/computer.md). Для запуска Linux требуется не менее 8 МБ, а 16 МБ - комфортный объём. Автономные программы работают с любым объёмом.

Оперативная память бывает следующих объёмов:
- 1 МБ
- 2 МБ
- 4 МБ
- 8 МБ
- 16 МБ
- 32 МБ

Планки названы по своему объёму, например "Память (16MB)". Из двух планок одного объёма можно скрафтить одну планку следующего объёма. Все установленные планки складываются. Каждый мегабайт памяти также увеличивает энергию, потребляемую машиной.

Для изменения памяти требуется перезагрузка машины.
