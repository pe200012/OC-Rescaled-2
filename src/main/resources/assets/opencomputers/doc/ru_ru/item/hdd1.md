# Жесткий диск

![Spaaaace.](oredict:oc:hdd1)

Жесткие диски - это основной носитель информации в OpenComputers. Они бывают объёмом 16, 32 и 64 МБ. Каждый из них является сырым диском в Linux: `/dev/vda` - первый, `/dev/vdb` - следующий, и так далее. На первый жесткий диск Linux устанавливается автоматически, когда [компьютер](../general/computer.md) запускается впервые. Остальные диски изначально пусты; подготовьте их командами `mke2fs` и `mount`. Меняйте жесткие диски только при выключенной машине.

Жесткие диски могут быть помещены в [RAID](../block/raid.md), который объединяет их в одну файловую систему OpenComputers. Linux видит её только как устройство `filesystem` на шине устройств, а не как диск. Помните, что при помещении жесткого диска в [RAID](../block/raid.md) вся информация на нём будет стерта.
