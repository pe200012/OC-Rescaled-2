# Контейнер для улучшения

![Может хранить улучшение.](oredict:oc:upgradeContainer1)

Контейнер для улучшения - это улучшение-контейнер для [роботов](../block/robot.md), которое предоставляет в готовых [роботах](../block/robot.md) слот, в который можно помещать обычные улучшения. Слот принимает улучшения любого уровня. В отличие от обычных улучшений, сложность контейнеров вдвое выше сложности обычных улучшений. Обратитесь к документации по [роботу](../block/robot.md) и [сборщику](../block/assembler.md) для сведений о сложности.
