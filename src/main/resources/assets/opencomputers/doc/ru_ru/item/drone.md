# Дрон

![Большой брат пытается следить за тобой.](item:OpenComputers:item@84)

Дроны создаются из [корпуса дрона](droneCase1.md) в [сборщике](../block/assembler.md). Это [роботы](../block/robot.md) на основе сущностей, немного дешевле и с ограниченной функциональностью. Они также способны двигаться иначе и гораздо быстрее [роботов](../block/robot.md), а управляются обычно с помощью клиентской программы на [компьютере](../general/computer.md). Дрон выполняет автономную программу из своего [EEPROM](eeprom.md), чтобы ожидать команды для выполнения или действовать самостоятельно.
