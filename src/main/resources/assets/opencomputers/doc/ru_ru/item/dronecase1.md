# Корпус дрона

![Полетели.](oredict:oc:droneCase1)

Корпус дрона используется для создания [дронов](drone.md) в [сборщике](../block/assembler.md). [Дроны](drone.md) - легковесные, быстрые и очень мобильные устройства с ограниченной функциональностью (доступно меньше слотов для компонентов и улучшений). В отличие от [роботов](../block/robot.md), они не могут использовать инструменты и взаимодействуют с игровым миром ограниченно.

Их ограничения компенсируются скоростью передвижения и низкими энергозатратами. Они хорошо подходят для переноса небольших количеств предметов и идеальны для разведки. Использование [дрона](drone.md) вместе с [роботом](../block/robot.md) дает большие возможности, где [робот](../block/robot.md) выполняет тяжелую работу, а [дрон](drone.md) предоставляет информацию об окружении и переносит предметы в центральное хранилище и обратно.

Как и [микроконтроллеры](../block/microcontroller.md), [дроны](drone.md) не имеют диска. Они выполняют автономную программу из своего [EEPROM](eeprom.md). Соответственно, [EEPROM](eeprom.md) может быть изменен объединением [дрона](drone.md) с другим [EEPROM](eeprom.md) на верстаке; старый [EEPROM](eeprom.md) при этом будет возвращен в инвентарь игрока.

Существует только один вид корпуса дрона (плюс творческий). Он позволяет использовать следующие компоненты:
- 1 [процессор](cpu1.md)
- [планки памяти](ram1.md)
- 1 [EEPROM](eeprom.md)
- Платы расширения
- Улучшения

Каждый слот принимает предметы любого уровня.
