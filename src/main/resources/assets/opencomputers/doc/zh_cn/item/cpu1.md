# CPU

![脑——子——](oredict:oc:cpu1)

中央处理器是每台[电脑](../general/computer.md)或[服务器](server1.md)的核心部件。它是一个运行Linux或裸机程序的64位RISC-V处理器。

CPU只有一种，其时钟频率可以是25、50、100或200 MHz。潜行使用CPU物品即可在它们之间切换。新的CPU以50 MHz运行。时钟越快，程序运行得越快，但耗电也越多。

CPU最多支持16个组件。对[服务器](server1.md)来说，[组件总线](componentBus1.md)可以进一步提升这一上限。如果[电脑](../general/computer.md)连接的组件数量超过上限，会无法开机。如果它正在运行，那么会崩溃。
