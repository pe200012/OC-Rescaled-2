# 服务器

![为您服务。](oredict:oc:server1)

服务器是高级形式的[电脑](../general/computer.md)。和其他电脑一样，它们运行Linux。手持它们使用即可进行配置，就像打开背包或末影袋一样。服务器在安装进[机架](../block/rack.md)后也能进行配置，方式为与它们互动（瞄准[机架](../block/rack.md)正面的对应位置点击）。要让服务器开始工作，需要将其装进[机架](../block/rack.md)中。详细信息请参见[机架](../block/rack.md)条目。

服务器只有一种（另有一种创造模式服务器）。它可安装如下组件：
- 1x [CPU](cpu1.md)
- [内存条](ram1.md)
- [硬盘](hdd1.md)
- [组件总线](componentBus1.md)
- 扩展卡
- 1x [EEPROM](eeprom.md)

每个槽位都可以放入任何规格的物品。
