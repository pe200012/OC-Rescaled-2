# 显示屏

![看见没？](oredict:oc:screen1)

显示屏用于显示[电脑](../general/computer.md)的输出。Linux控制台直接绘制在显示屏上，因此不需要[显卡](../item/graphicsCard1.md)；显卡仍然是程序可以调用的组件。显示屏的分辨率最高为160x50字符，支持256色，控制台为80x24字符。这也包括内置于[机器人](robot.md)和[平板电脑](../item/tablet.md)中的显示屏。

控制台会使用与电脑机箱相接的显示屏，没有的话则使用网络中的第一块显示屏。只有连接到该显示屏的[键盘](keyboard.md)才能在其上输入。用线缆连在一起的多台电脑不会在彼此的显示屏上绘制内容。

若显示屏相邻摆放且朝向一致，它们可以组合为多方块显示屏。对朝上或朝下的显示屏而言，旋转方向还要保证一致。手持显示屏时，会叠加显示一个箭头，指示朝向。

显示屏的可用分辨率不受尺寸影响。为了控制相邻显示屏是否进行连接，可以用任意染料对显示屏进行染色，只需手持染料右键单击显示屏即可。染料不会消耗，但显示屏被破坏后不会保留所染的颜色。颜色不同的显示屏不会互相连接。

显示屏还支持鼠标输入。点击操作既可以在显示屏的GUI中进行（只有连接[键盘](keyboard.md)的前提下才能打开GUI），也可以在世界中潜行右键单击显示屏。当程序在帧缓冲上绘制时，鼠标位置与按键会以帧缓冲像素为单位上报（/dev/input/event1）。在显示屏的GUI中，不按键移动鼠标也会移动指针。

Linux还有一个帧缓冲/dev/fb0，大小为320x192像素。程序一旦在其上绘制，显示屏就会显示这些像素。当绘制停止一秒后控制台再次输出内容，显示屏就会回到文本显示。可以试试`micropython /mnt/builtin/example/framebuffer.py`。
