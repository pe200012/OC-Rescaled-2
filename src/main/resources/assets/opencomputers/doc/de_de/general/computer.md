# Computer

Computer werden aus verschiedenen [Blöcken](../block/index.md) und Komponenten zusammengebaut. Das Mindeste für einen brauchbaren Computer sind ein [Gehäuse](../block/case1.md), ein [Bildschirm](../block/screen1.md) und eine [Tastatur](../block/keyboard.md). Die [Tastatur](../block/keyboard.md) muss auf dem [Bildschirm](../block/screen1.md) platziert werden, entweder an dessen Seiten oder direkt davor. Der Computer verwendet den [Bildschirm](../block/screen1.md), der sein [Gehäuse](../block/case1.md) berührt, falls es einen gibt, sonst den ersten, den er in seinem Netzwerk findet, und liest nur [Tastaturen](../block/keyboard.md), die an diesem [Bildschirm](../block/screen1.md) angebracht sind. Mehrere Computer, die mit [Kabeln](../block/cable.md) verbunden sind, greifen daher nicht auf die [Bildschirme](../block/screen1.md) der anderen zu.

Im [Gehäuse](../block/case1.md) werden die Komponenten untergebracht: ein [Hauptprozessor (CPU)](../item/cpu1.md), [Speicher (RAM)](../item/ram1.md), ein [EEPROM](../item/eeprom.md) mit dem Linux-Bootloader und in der Regel eine [Festplatte (HDD)](../item/hdd1.md). Weitere Komponenten bringen zusätzliche Fähigkeiten: [Netzwerkkarten](../item/lanCard.md) und [Internetkarten](../item/internetCard.md) werden in Linux zu Netzwerkschnittstellen, eine [Redstonekarte](../item/redstoneCard1.md) erlaubt es Programmen, Redstone zu lesen und zu setzen, und so weiter. Für die Konsole wird keine [Grafikkarte](../item/graphicsCard1.md) benötigt. Eine Schritt-für-Schritt-Anleitung zum Aufbau findest du unter [Erste Schritte](quickstart.md).

Der Computer führt [Linux](linux.md) auf einem emulierten 64-Bit-RISC-V-Prozessor aus. Beim ersten Start mit einer [Festplatte](../item/hdd1.md) wird Linux auf dieser Festplatte installiert. Ohne [Festplatte](../item/hdd1.md) läuft ein Live-System aus dem Speicher, das alles vergisst, sobald der Computer stoppt. Weitere [Festplatten](../item/hdd1.md) und [Disketten](../item/floppy.md) sind in Linux einfache Datenträger, siehe [Linux](linux.md).

Ein laufender Computer wird samt Speicher mit der Welt gespeichert und macht weiter, wo er aufgehört hat, sobald sein Chunk wieder geladen wird. Fahre ihn in Linux mit `poweroff` herunter oder starte ihn mit `reboot` neu. Änderungen an [Speicher](../item/ram1.md), [Festplatten](../item/hdd1.md), Netzwerkkarten oder [EEPROM](../item/eeprom.md) werden wirksam, wenn der Computer neu startet; andere Komponenten können im laufenden Betrieb hinzugefügt und entfernt werden.

Der letzte Schritt besteht darin, den Computer mit einer Energiequelle zu versorgen. OpenComputers ist mit den meisten größeren Energiemods kompatibel, und viele Blöcke können direkt an die Energiequelle angeschlossen werden. Ob ein Block an externe Energie angeschlossen werden kann, erkennst du daran, dass sein Tooltip einen Eintrag über die Geschwindigkeit der Energieumwandlung enthält. Wie viel ein Computer verbraucht, hängt von der Taktrate seines [Hauptprozessors](../item/cpu1.md) und der Größe seines [Speichers](../item/ram1.md) ab.
Für ein größeres Netzwerk mit mehreren Computern können ein [Energiekonverter](../block/powerConverter.md) (konvertiert Energie verschiedener Mods zum internen Energietyp von OpenComputers), ein [Energieverteiler](../block/powerDistributor.md) (verteilt Energie auf verschiedene Computer im Netzwerk) und ein [Kondensator](../block/capacitor.md) (Energiespeicher für das Netzwerk) verwendet werden, um die Computer über [Kabel](../block/cable.md) miteinander zu verbinden.
