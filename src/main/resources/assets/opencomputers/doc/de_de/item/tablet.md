# Tablet

![Berühr' mich, wenn du kannst.](item:OpenComputers:item@68)

Tablets werden gebaut, indem ein [Tabletgehäuse](tabletCase1.md) in einer [Elektronik-Werkbank](../block/assembler.md) eingesetzt, wie gewünscht konfiguriert und montiert wird. Tablets sind tragbare Computer, die nicht direkt mit der Welt interagieren können. Das bedeutet, dass beispielsweise [Redstonekarten](redstoneCard1.md) darin nicht funktionieren. Einige Upgrades funktionieren jedoch, wie das [Schild-I/O-Upgrade](signUpgrade.md) oder das [Kolbenupgrade](pistonUpgrade.md).

Das Tablet ermöglicht zudem die Installation eines einzelnen Container-Upgrades. Der vom Container bereitgestellte Slot kann in der alternativen Benutzeroberfläche des Tablets geöffnet werden (Umschalttaste-Rechtsklick mit dem Tablet in der Hand). Dies fährt zudem das Tablet herunter.

Tablets führen Linux aus. Im Gegensatz zu Computern starten Tablets neu, nachdem die Welt neu geladen wurde oder nachdem sie etwa 10 Sekunden lang nicht im Inventar eines Spielers waren.

Tablets können in ein [Ladegerät](../block/charger.md) eingesetzt werden, um ihre Energie aufzufüllen.

Eine weitere erweiterte Funktion des Tablets ist das Generieren von Signalen mit Informationen über bestimmte Blöcke in der Welt, indem es etwa eine Sekunde lang auf einen Block angewendet wird (d.h. die rechte Maustaste gedrückt halten). Ein kurzes Piepen weist darauf hin, dass das Signal generiert wurde. Dies funktioniert nur, wenn Upgrades im Tablet installiert sind, die das Signal mit Informationen füllen. Beispielsweise fügt der [Geolyzer](../block/geolyzer.md) Informationen über den Block selbst hinzu (z.B. die Härte), das [Navigations-Upgrade](navigationUpgrade.md) die Koordinaten des Blocks relativ zum Spieler, der das Tablet hält. Der zu analysierende Block wird mit einem grünen Overlay markiert, während das Tablet in der Hand gehalten wird.
