# Komponentenschnittstelle

![Ich brauche mehrrrr.](oredict:oc:componentBus1)

Eine Komponentenschnittstelle ist ein [Server](server1.md)spezifisches Upgrade, das es dem [Server](server1.md) erlaubt, mit mehr Komponenten gleichzeitig zu kommunizieren, ohne sich abzuschalten. Jede Komponentenschnittstelle fügt dem, was die [CPU](cpu1.md) unterstützt, 16 Komponenten hinzu.
