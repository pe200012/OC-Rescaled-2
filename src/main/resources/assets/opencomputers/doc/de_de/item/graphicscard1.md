# Grafikkarte

![Schicke Bilder.](oredict:oc:graphicsCard1)

Die Grafikkarte ist eine Komponente, die Programme aufrufen können, um Text auf einem verbundenen [Bildschirm](../block/screen1.md) darzustellen. Für die Linux-Konsole wird sie nicht benötigt, da diese direkt auf den Bildschirm zeichnet.

Es gibt nur eine Sorte Grafikkarte. Wie alle [Bildschirme](../block/screen1.md) unterstützt sie Auflösungen bis zu 160x50 und 256 Farben.
