# Upgrade-Container

![Kann Upgrade haben.](oredict:oc:upgradeContainer1)

Der Upgrade-Container ist ein Container-Upgrade für [Roboter](../block/robot.md). Er stellt in den fertigen [Robotern](../block/robot.md) einen Slot zur Verfügung, in dem normale Upgrades platziert werden können. Der Slot nimmt Upgrades jeder Stufe auf. Im Gegensatz zu normalen Upgrades ist die Komplexität von Containern doppelt so groß wie die normaler Upgrades. Für mehr Informationen über Komplexität siehe [Roboter](../block/robot.md) und [Elektronik-Werkbank](../block/assembler.md).
