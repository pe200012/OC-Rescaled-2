# Server

![Serviert alles korrekt.](oredict:oc:server1)

Server sind eine Form von hochstufigen [Computern](../general/computer.md). Sie führen Linux aus wie jeder andere Computer. Sie können konfiguriert werden, indem man sie in der Hand hält und benutzt - wie beim Öffnen eines Rucksacks oder Endertasche. Server können auch nach dem Einbau in einen [Serverschrank](../block/rack.md) konfiguriert werden, indem man sie aktiviert (auf die entsprechende Position an der Vorderseite des [Serverschranks](../block/rack.md) zielen). Zum Betrieb muss der Server in einem [Serverschrank](../block/rack.md) platziert werden. Für Informationen siehe den Eintrag des [Serverschranks](../block/rack.md).

Es gibt nur eine Art von Server (plus eine Kreativ-Variante). Er kann folgende Komponenten aufnehmen:
- 1x [CPU](cpu1.md)
- [RAM](ram1.md)
- [HDD](hdd1.md)
- [Komponentenbus](componentBus1.md)
- Erweiterungskarten
- 1x [EEPROM](eeprom.md)

Jeder Slot nimmt Gegenstände jeder Stufe auf.
