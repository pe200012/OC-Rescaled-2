# Karten-Behälter

![Ich kann Karten haben!!](oredict:oc:cardContainer1)

Der Karten-Behälter ist ein Behälter-Upgrade für [Roboter](../block/robot.md), das es erlaubt, Karten im laufenden Betrieb in [Roboter](../block/robot.md) einzusetzen oder aus ihnen zu entfernen. Der Slot nimmt Karten jeder Stufe auf. Im Gegensatz zu normalen Upgrades ist die Komplexität von Behältern doppelt so hoch wie die normaler Upgrades. Details zur Komplexität von Robotern sind [hier](../block/robot.md) zu finden.
