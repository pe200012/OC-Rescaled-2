# Akkuupgrade

![Aus Metall angefertigt.](oredict:oc:batteryUpgrade1)

Dieses Upgrade erhöht den internen Energiespeicher von Geräten wie [Robotern](../block/robot.md) und [Tablets](tablet.md). Sie können damit länger betrieben werden, ohne zu einem [Ladegerät](../block/charger.md) zurückkehren zu müssen.
