# Elektronik-Werkbank

![Harder, better, faster, stronger.](oredict:oc:assembler)

Die Elektronik-Werkbank ist eine fortgeschrittene Maschine, die verwendet werden kann, um komplexere elektronische Geräte wie [Roboter](robot.md), [Drohnen](../item/drone.md) oder [Tablets](../item/tablet.md) zu bauen. Sie benötigen eine große Menge an Energie, um Geräte zu montieren, daher wird empfohlen, sie mittels einer [Kondensatorbank](capacitor.md) ausreichend mit Energie zu versorgen.

Um ein Gerät mit Hilfe der Elektronik-Werkbank zu bauen, muss das Basisteil des Geräts eingesetzt werden. Für [Roboter](robot.md) ist dies ein [Computergehäuse](case1.md), für [Tablets](../item/tablet.md) hingegen ein [Tabletgehäuse](../item/tabletCase1.md). So wie es bei jedem OpenComputers-Inventar der Fall ist, können diese Teile nur in bestimmte Slots eingesetzt werden. Wird der Mauszeiger über einen Slot gehalten, werden die Teile im eigenen Inventar markiert, die in diesen Slot passen. Wenn NEI geöffnet und auf OpenComputers-Items gefiltert ist, werden kompatible Items auch dort markiert. Anschließend werden alle weiteren Teile eingesetzt, die das Gerät enthalten soll. Besonders wichtig ist es, eine [Festplatte](../item/hdd1.md) und ein [EEPROM](../item/eeprom.md) mit einem Bootloader bereitzustellen, damit [Linux](../general/linux.md) starten kann (zum Beispiel kann man bei Robotern ein [Diskettenlaufwerk](diskDrive.md) installieren, um später [Disketten](../item/floppy.md) einzusetzen oder zu entfernen). Bei den meisten Geräten kann das [EEPROM](../item/eeprom.md) später geändert werden, indem das Gerät mit einem anderen [EEPROM](../item/eeprom.md) zusammen gecraftet wird. Das vorhandene [EEPROM](../item/eeprom.md) wird in das Inventar zurückgelegt.

Zu bedenken ist außerdem, dass [Roboter](robot.md) einen [Bildschirm](screen1.md) benötigen, um einen zu haben, und dass zum Schreiben auf dem [Bildschirm](screen1.md) eine [Tastatur](keyboard.md) installiert sein muss. In [Tablets](../item/tablet.md) ist der [Bildschirm](screen1.md) bereits im [Tabletgehäuse](../item/tabletCase1.md) vorhanden, aber es ist nötig, eine [Tastatur](keyboard.md) zu installieren, falls auf dem [Tablet](../item/tablet.md) geschrieben werden soll.

Sobald alles an seinem Platz liegt, wird mit dem Startknopf die Prozedur gestartet. Dann muss gewartet werden, bis das Gerät montiert und geladen ist. Es ist wichtig zu bedenken, dass das Gerät *nicht geändert werden kann*, sobald es montiert wurde. Wenn etwas fehlt oder ein Fehler gemacht wurde, muss das Gerät mit dem [Recycler](disassembler.md) wieder demontiert werden, was eine geringe Wahrscheinlichkeit von Teilverlust mit sich bringt.
