# Roboter

![Er hieß Retobor.](block:OpenComputers:robot)

Im Gegensatz zu [Computern](../general/computer.md) können Roboter sich bewegen und mit der Welt fast wie ein Spieler interagieren. Sie können jedoch *nicht* mit externen Komponenten interagieren! Wenn die Kommunikation mit einem [Computer](../general/computer.md) oder anderen Robotern benötigt wird, muss beispielsweise eine [Drahtlosnetzwerkkarte](../item/wlanCard1.md) verwendet werden, oder ein Low-Level-Protokoll mit Redstonesignalen über eine [Redstonekarte](../item/redstoneCard1.md) erstellt werden.

Roboter werden gebaut, indem ein [Computergehäuse](case1.md) in einer [Elektronik-Werkbank](assembler.md) platziert wird. Roboter führen Linux aus, genau wie [Computer](../general/computer.md). Unter Linux stellt `import robot` in Micropython Funktionen wie `robot.forward()`, `robot.turn_left()`, `robot.swing()` und `robot.place()` bereit; `robot.component` enthält jede Roboter-Methode. Die Maschine pausiert, während der Roboter sich bewegt oder dreht.

Eine Vielfalt von Upgrades kann in Robotern verwendet werden, um ihre Funktionen zu erweitern. Dazu zählen unter anderem das [Inventar](../item/inventoryUpgrade.md), der [Inventarcontroller](../item/inventoryControllerUpgrade.md), [Tankupgrades](../item/tankUpgrade.md) oder das [Navigationsupgrade](../item/navigationUpgrade.md). [Upgrade-](../item/upgradeContainer1.md) und [Karten](../item/cardContainer1.md)container können im Roboter platziert werden, um flexiblen Einbau und Ausbau von Upgrades und Komponenten zu ermöglichen. Auch ein [Diskettenlaufwerk](diskDrive.md) kann eingebaut werden, um den Einsatz von [Disketten](../item/floppy.md) zu ermöglichen. Wird eine [Festplatte](../item/hdd1.md) in den Roboter gelegt, installiert er beim ersten Start [Linux](../general/linux.md) darauf.
