# Recycler

![Bau' es auf, reiß' es ab.](oredict:oc:disassembler)

Der Recycler kann verwendet werden, um die meisten Items in OpenComputers in ihre ursprünglichen Bestandteile zu zerlegen. Dies ist besonders nützlich, um Materialien von unnütz gewordenen Bauteilen zurückzubekommen, oder um Geräte zu demontieren, die nicht länger gebraucht werden oder inkorrekt gebaut wurden (z.B. [Roboter](robot.md) ohne [Betriebssystem](../general/linux.md)).

Die Demontage benötigt eine lange Zeit und etwas Energie. Es besteht zudem eine geringe Wahrscheinlichkeit, dass eine Komponente verloren geht (dies wird für jede Komponente einzeln angewendet).
