# Computergehäuse

![Just in case.](oredict:oc:case1)

Das Computergehäuse enthält die Teile eines [Computers](../general/computer.md): [CPU](../item/cpu1.md), [RAM](../item/ram1.md), [Festplatten](../item/hdd1.md), Erweiterungskarten und ein [EEPROM](../item/eeprom.md). Es gibt eine Art von Computergehäuse; zusätzlich existiert ein Gehäuse nur für den Kreativ-Modus. Jeder Slot nimmt Items jeder Stufe auf.

Ein Computer führt Linux aus. Er startet das, was auf seinem EEPROM liegt, und auf der ersten Festplatte wird Linux beim ersten Start des Computers automatisch installiert. Ohne Festplatte läuft Linux als Live-System aus dem Speicher, und nichts bleibt erhalten, wenn es anhält. Computergehäuse können ebenfalls in einer [Elektronik-Werkbank](assembler.md) platziert werden, um [Roboter](robot.md) zu bauen.

Ein am Gehäuse anliegender [Bildschirm](screen1.md) wird für die Konsole verwendet, und eine an diesem Bildschirm angebrachte [Tastatur](keyboard.md) dient zum Schreiben.
